{% comment %} Modal Alpine reusable. REGLA DEL PROYECTO: NUNCA usar `alert()`, `confirm()` o `prompt()` nativos del browser en pantallas custom. Usar SIEMPRE este modal. Los nativos rompen el look visual, bloquean el thread y no se pueden estilar — los reemplazamos por este componente Tailwind + Alpine. USO desde otro template: 1. Incluí este partial al final del componente Alpine (dentro del div con `x-data`): {% include "partials/_modal_alpine.html" %} 2. En tu función Alpine, mergeá el state del modal con tu state usando spread (`...modalState()`): function miPantalla() { return { ...miEstadoInicial, ...modalState(), } } 3. Para mostrar algo, llamá a `abrirModal(...)`: this.abrirModal({ tipo: 'warning', // 'info' | 'warning' | 'error' | 'confirm' titulo: 'Atención', mensaje: 'Texto opcional explicando qué pasó.', lista: ['Item 1', 'Item 2'], // opcional, render como bullets okLabel: 'Entendido', cancelLabel: 'Cancelar', // solo si tipo='confirm' callback: () => { // se ejecuta al confirmar window.location.href = '/admin/'; }, }); - tipo 'confirm' muestra botones Cancelar + OK. - los demás tipos muestran solo OK. - el callback NO se ejecuta si el user aprieta Cancelar. - el modal NO se cierra con click en el overlay ni con Esc — el operador tiene que confirmar explícitamente. {% endcomment %}
