{% load static %} {% comment %} Grilla de precios — pantalla tipo planilla (estilo Google Sheets) para editar precios y stock de muchos artículos a la vez. Filosofía: - Carga paginada vía API JSON (50 por defecto). Cargar miles de inputs en el DOM se vuelve muy lento y arruina la UX. - Cambios "en memoria": el operador puede pinchar varios precios sin commitear nada; solo se postea al apretar "Guardar". - Los cambios sin guardar se mantienen entre páginas y filtros, pero advertimos con confirm() para que el operador no los pierda por error. - Bulk apply: seleccionar filas con checkbox y aplicar +monto o +porcentaje a precio minorista y/o mayorista. Estilo: Tailwind por CDN + Alpine 3 para coherencia con `venta/templates/venta/venta_nueva.html`. No usamos chrome de django-material-admin porque esta es una pantalla full-width "de operación" y no entra cómodo dentro del listado del admin. {% endcomment %} Grilla de precios — VentaStockManager {% comment %} Tailwind por CDN. Suficiente para una pantalla interna (sin necesidades de SEO ni Core Web Vitals). Si en algún momento vemos lentitud o FOUC molesto, se puede pasar a un build real. {% endcomment %} {% comment %} Alpine en defer: queremos que esté disponible antes de DOMContentLoaded para que `x-data` se inicialice, pero no bloquear el primer paint. `defer` cumple las dos cosas. {% endcomment %} {% comment %} Form oculto solo para que Django setee la cookie csrftoken cuando renderiza esta página (la usamos al hacer POST a /api/grilla/guardar/). {% endcomment %}
