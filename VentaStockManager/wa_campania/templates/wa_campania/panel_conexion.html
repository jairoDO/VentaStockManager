{% comment %} Panel de conexión WhatsApp. UX: una sola pantalla que polea /api/conexion/status/ cada 3 segundos y reacciona según el estado: - state=CONNECTED → tarjeta verde con número + nombre + botón "Desconectar" (logout, regla del proyecto: confirm en modal). - state=UNPAIRED|SCAN_QR|... → tarjeta amarilla con QR. El apunta a /api/conexion/qr.png?_=: el cache-busting hace que cada poll traiga el QR fresco (rotan cada 30s). - state=connection_error → tarjeta roja: el wa-bot no responde. Estilo: Tailwind CDN + Alpine 3. Sin chrome del admin (es una página operativa, no de gestión de datos). Mismo patrón que configuracion/panel_tareas.html. {% endcomment %} Conexión WhatsApp — VentaStockManager {% comment %} Form vacío para que Django setee la cookie csrftoken (la usamos en los POST de logout/restart/test). {% endcomment %}
